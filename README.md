# Калькулятор на TypeScript

Консольное приложение для ввода двух чисел и выполнения арифметических операций.

## Запуск

1. Установите Node.js.
2. В папке проекта выполните `npm install`.
3. Запустите приложение командой `npm start`.

## Пункты меню

- `1` — ввести два числа
- `2` — выполнить сложение
- `3` — выполнить вычитание
- `4` — выполнить деление
- `5` — возвести первое число в степень второго
- `0` — завершить работу

Функции реализованы в отдельных модулях, добавленных в соответствующих ветках Git.
