# Родительский репозиторий

Это основная версия проекта. Изменения из рабочих веток предлагаются через pull request, чтобы их можно было проверить до объединения.

## Порядок работы

1. Создать отдельную ветку для задачи.
2. Внести и зафиксировать изменение.
3. Открыть pull request в основную ветку.
4. Проверить изменения и выполнить слияние.
